# Авторские данные Studio

Эта папка содержит редактируемые черновики, а не Python-код игры.

- `global-catalogs.studio.json` — общий каталог видов, языков и объединений.
- `worlds/*.draft.json` — редактируемые основы миров.
- `upload/` — опубликованные файлы, готовые для переноса через Cyberduck в
  одноимённые серверные подпапки.
- `upload/promocodes/ANI-TEST-AUDT.json` — истёкший проверочный промокод;
  он нужен только для аудита связки и не выдаёт награду.

Опубликованные файлы всегда создаются проверяемыми экспортерами Studio из
черновиков. Игровой код не содержит копию этого содержимого.
