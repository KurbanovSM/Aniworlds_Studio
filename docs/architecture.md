# Архитектура Aniworlds Studio

Studio — отдельное локальное desktop-приложение на Python 3.12 и Tkinter без
сетевых зависимостей. Интерфейс находится в `app.py`, а создание, проверка и
сериализация файлов — в `promo_export.py`.

Генератор создаёт два серверных контракта:

- версия 1 — промокод ходов;
- версия 2 — промокод стандартного периода подписки.

Для подписки UI передаёт только лимит активаций. Вид награды, версия схемы и код
создаются программой, срок не входит в файл. Сервер берёт его из своего
канонического предложения подписки.

Окно подбирает минимальный размер после расчёта реальной высоты элементов
Tkinter, поэтому масштабирование Windows не обрезает поля и основные кнопки.

Экспорт использует исключительно локальный путь, выбранный пользователем.
Существующий файл не перезаписывается. Доставка через Cyberduck остаётся ручной
операцией вне Studio.
