# Aniworlds Studio

Отдельная автономная программа для подготовки данных Aniworlds AI. Studio не
подключается к VPS и не содержит адрес сервера: она сохраняет проверенные файлы
локально, после чего их можно перенести на сервер через Cyberduck.

Верхние разделы расположены в порядке `Глобальные настройки`, `Общие каталоги`,
`Миры`, `Промокоды`. Глобальные настройки:

- одинаковы для всех миров;
- содержат лимит способностей при создании, лимит изучаемых способностей и число
  подтверждённых уроков;
- сохраняются отдельным файлом `global-gameplay.settings.json` для папки `settings`.

«Общие каталоги» содержат основные карточки рас и видов, языков и объединений.
Категории существ, уровни мышления и способы общения в формах дословно повторяют
серверные справочники игры. При запуске Studio показывает исходные карточки из
редактируемого файла данных: автор может удалить, изменить или дополнить их, а
Studio не подмешивает записи из кода или миграций игры.
Редактируемый черновик сохраняется как `global-catalogs.studio.json`, а команда
«Опубликовать для сервера» создаёт `global-catalogs.catalog.json` для папки
`catalogs`. Мир хранит только ID выбранных записей и собственные связи — названия,
описания, мышление и способы общения в файл мира повторно не копируются.

Генератор промокодов:

- промокод подписки: меняются общий лимит активаций и необязательный срок новых
  активаций; уже выданная подписка после этого срока не пропадает;
- промокод ходов: задаются ходы, лимит активаций и необязательное окончание;
- код `ANI-XXXX-XXXX` создаётся автоматически;
- каждый результат сохраняется отдельным JSON-файлом с именем кода.

Редактор миров позволяет:

- создавать и открывать локальные черновики вселенной;
- открывать опубликованный мир версии 4 как редактируемую копию и сохранять его
  под новым именем, не перезаписывая исходный серверный файл;
- редактировать несколько периодов, лор и начальную ситуацию;
- задавать валюту и название запаса сил в двух отдельных разделах;
- сначала создавать независимый каталог локаций, затем добавлять локации в периоды;
- разрешать переходы только между локациями одного периода;
- задавать коэффициент цен локации в черновике Studio;
- задавать от одного до десяти стартовых наборов на период и до 10 объявленных предметов
  в каждом наборе;
- выбирать виды, расы, языки, объединения и черты характера из общих каталогов, а предметы,
  магазины, подготовленных персонажей и NPC создавать для мира;
- задавать персонажам периоды, происхождение, мышление, языки, черты, способности,
  участие и лидерство в объединениях;
- задавать предметам свойства, ограничения, цену, допустимые магазины, частоту появления
  и необязательный предел экземпляров на мир;
- заполнять каталоги карточками с подписанными полями, без ручного ввода JSON;
- проверить данные и просмотреть итоговый JSON до публикации;
- создать локальный пакет версии 4 `*.world.json` для ручной загрузки в серверную папку
  `worlds` через Cyberduck.

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\aniworlds-studio.exe
```

После установки программу можно открывать двойным щелчком по
`start-studio.cmd` в корне проекта.

Глобальная настройка загружается в `settings`, опубликованные общие каталоги — в
`catalogs`, основа мира версии 4 — в `worlds`, промокод — в `promocodes` общего
дерева Studio. Программа не отправляет файлы на сервер самостоятельно.
`global-catalogs.studio.json` остаётся только редактируемым черновиком.

Проверенные авторские черновики хранятся в `content`, а готовое дерево ручной
загрузки — в `content/upload`. Открытие этих файлов через Studio сохраняет их
редактируемость; опубликованные JSON остаются отдельными неизменяемыми
артефактами серверных контрактов.

Aniworlds AI принимает отдельный общий каталог версии 2 и пакеты миров версии 4.
Импортёр сначала проверяет общий каталог, затем все миры и сохраняет весь набор
одной транзакцией. [Порядок интеграции](docs/game-integration-notes.md) является
обязательной инструкцией перед загрузкой файлов на VPS.

Коэффициент цен входит в пакет мира версии 4, сохраняется игровым сервером у
локации и применяется им к базовой цене товара при покупке. Studio только
редактирует значение; формула и округление остаются единственной игровой
механикой сервера. Кириллические ID общих карточек передаются без скрытых
псевдонимов или автоматической замены.
